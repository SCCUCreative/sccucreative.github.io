# sccucreative.github.io

The main GitHub Pages site for the SCCUCreative account, served at **https://scottfree.live**.

- `index.html` is the Scott Free "coming soon" holding page, with a link to the Six Human Needs Quiz.
- Every other repo in this account with Pages turned on is served under this domain at `scottfree.live/<repo-name>/`, for example the quiz at `scottfree.live/human-needs-quiz/`.
- The custom domain is set in this repo's **Settings → Pages → Custom domain** (GitHub keeps it in the `CNAME` file).
- The NUBU coming-soon page for **nubuverse.com** lives in its own repo, `nubuverse`, which has its own custom domain.
